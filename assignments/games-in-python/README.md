# 📘 Assignment: Games in Python

## 🎯 Objective

Build a playable Python game that uses user input, loops, conditionals, and strings to create an engaging experience for the player.

## 📝 Tasks

### 🛠️ Build a Hangman Game

#### Description
Create a text-based Hangman game where a player tries to guess a hidden word before running out of attempts.

#### Requirements
Completed program should:

- Randomly select a word from a predefined list of words
- Show the current guessed state using underscores or blanks for unguessed letters
- Accept single-letter guesses from the player
- Update the revealed word after each correct guess
- Track and display the number of incorrect guesses remaining
- End the game when the player guesses the word or runs out of attempts
- Display a clear win or lose message at the end of the round

### 🛠️ Improve the Game Experience

#### Description
Add small but meaningful improvements to make the game easier to use and more polished for players.

#### Requirements
Completed program should:

- Prevent duplicate guesses from being counted multiple times
- Tell the player when a guess is invalid or already used
- Keep the gameplay loop running until the player chooses to exit or starts a new game
- Use clear prompts and readable output so the game is easy to follow
- Include at least one simple feature that makes the game feel more complete, such as replay support or a score tracker
